## ⚠️ 本版仅限 OPPO Find X9 Pro / Find X 系列

本仓库版本深度整合了 ColorOS 独有的系统特性，**非 OPPO 设备请勿下载**。

### 🔀 非 OPPO 用户请改用自适应版

👉 **[zhq380/bing-rewards-assistant](https://github.com/zhq380/bing-rewards-assistant)**

通用自适应版，Material You 风格，600dp 自动限宽 + 自定义像素适配，覆盖所有 Android 8.0+ 设备。

## 🎨 ColorOS 独有的设计特性

| 特性 | 说明 |
|------|------|
| **光场设计** | ColorOS 16 Light Field 毛玻璃层级 |
| **流体云胶囊通知** | ColorOS 16 状态栏原生胶囊 |
| **极光引擎动效** | 无缝过渡跟手动效 |
| **潮汐引擎帧追踪** | 120Hz LTPO 高刷优化 |
| **应用分身直启** | OPPO user 999 分身空间 |
| **全宽无限制 UI** | 1.5K 宽屏原生铺满 |
| **系统动态取色** | Material You + OPPO 取色 |

## 📱 验证环境

- OPPO Find X9 Pro
- ColorOS 16.1 / Android 16 QPR1
- 骁龙 8 至尊版
- 1.5K 120Hz LTPO
